# 超星课表

基于学习通课程表构建的低网络要求且稳定的**移动端**课程表

## 如何使用

### 1.获取课程表链接

**1.手机版**📱
- 打开学习通
- 点击应用中心
- 寻找**学生课表**
- 进入后
   1. 出现课程✅：出现课程表后，点击右上角展开选项，再点击转发，点击复制链接
   2. 没有课程❌：很遗憾，学校不支持

**2.电脑版**💻
- 进入个人空间
- 右上角展开，点击**切换单位/角色**
- 确认后，主页会出现课程表
- 点击课程表右上角转发，复制链接

### 2.应用内导入
- 打开课表app
- 点击右上角第二个那个**输入链接**选项
- 粘贴进去刚刚得到的链接
- 如出现你的课程，恭喜成功

***

### 额外功能：以下仅限 *SDUST* 的现行教务系统
#### 考试成绩信息
- [x] 已完成
- 顶部可切换“课程表 / 考试信息”。成绩区域支持内部横向、纵向滚动，点击放大可占满内容区，再点击缩小恢复上下等高布局。
- 首次进入时输入教务系统账号密码。**成绩成功获取后保存到本机**，切换页面和重新启动不会自动请求；点击右上角刷新才重新获取。登录时可勾选“保存账号密码，下次自动登录”，账号密码存入系统安全存储；未勾选则不保存。重启后或会话失效时，刷新会尝试使用已保存的账号密码自动登录，失效后提示手动登录。**取消登录或刷新失败==不会==清空已有成绩**。

## 考试时间信息
- [x] 已完成
- 上半区显示当前学期的结课考试安排，包含课程、考试日期时间、地点、考试类型及周次节次，按考试时间排列并支持内部滚动。
